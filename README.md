# Muhammad Awais - Portfolio

**Live Website:** [https://portfolio-omega-lilac-rhuu3ens6y.vercel.app/](https://portfolio-omega-lilac-rhuu3ens6y.vercel.app/)

Welcome to the personal portfolio repository for Muhammad Awais, a Full-Stack AI Engineer & Computer Vision Researcher.

## About The Repository

This repository contains the source code for a modern, responsive, and dynamic portfolio website built using **Next.js (App Router)**.

### Key Features
- **Interactive UI**: Includes an advanced `Command Palette` and an `Assistant Drawer` for quick navigation and AI-driven assistance.
- **Dynamic Content**: Displays up-to-date experiences, research, projects, certifications, and skills.
- **Optimized Performance**: Built with modern web development standards leveraging Next.js static and dynamic rendering capabilities.

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment
This project is continuously deployed on Vercel. Any pushes to the `main` branch will automatically trigger a new build and deployment via Vercel's GitHub integration.
